# T02 Internationalisation

Probes in fresh processes under `en_GB.UTF-8`, `nl_NL.UTF-8` and `C.UTF-8` (the locales installed here), plus `OutDec = ","`.

## Checked

| Aspect | Result |
|---|---|
| Session locale after plot2 calls | unchanged in all three locales |
| Date axis labels | follow the system locale (January / januari) |
| Date category legend, `format2()` | always Dutch ("maart"), F003; under the C locale every date category plot warns "OS reports request to set locale to "nl_NL" cannot be honored" (F003) |
| Date category with two dates | 32 daily legend entries (F004, now also for `Date`) |
| `d` format | space-padded days, labels start with a space (F029) |
| `y.age`, `y.24h` | "jr"/"u" under a Dutch `LC_COLLATE`, "yrs"/"h" otherwise (F003) |
| `OutDec = ","` | comma decimals, full-stop thousands, consistent in axes and datalabels |
| Sorting of accented values | a, Ä, b, é, z in every locale |
| Non-ASCII column names, Greek and CJK titles | kept; wrapping counts only ASCII (F056) |
| Date-times in a non-UTC zone | labelled in their own zone |
| Message language | English, except default titles from `get_plot_title()` (F003) |

## Findings

No new finding; F003, F004, F029 extended, F056 confirmed.
